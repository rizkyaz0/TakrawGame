# Easter egg: penonton berjas di ujung tribun

- Bukan karakter yang bisa dipilih. Satu pemindaian 3D (`public/models/pojok.glb`, ±18 ribu segitiga,
  133 KB, dari file asli 71 MB lewat `scripts/optimize-glb.mjs` dengan tekstur 512 dan error 0,004)
  berdiri di ujung kanan tribun atas dan ikut melompat saat sorakan. Kodenya `loadCameo` di
  `src/scenery.ts`; dimuat malas dan hilang tanpa merusak arena kalau gagal.
- Model ini wajah orang sungguhan. Keputusan pemilik: dipakai sebagai easter egg, bukan karakter.
  Sebelum game dipublikasikan luas atau punya toko, pertimbangkan lagi soal hak atas wajah dan citra.
- Jangan dijadikan sasaran pukulan, bahan ejekan, atau item gacha.
- Rencana karakter rahasia gacha tetap perlu karakter maskot jajanan fiktif (belum ada).
