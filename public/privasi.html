Privasi

Takraw Clash · diperbarui 16 November 2026

Ringkasnya

Kamu bisa bermain sebagai tamu tanpa akun sama sekali. Akun Google bersifat pilihan, hanya untuk menyimpan progres di server dan membukanya di perangkat lain. Tidak ada iklan dan tidak ada alat pelacak atau analitik.

Kalau kamu masuk dengan Google

Login ditangani Supabase (basis data dan autentikasi) lewat Google. Dari akun Google, kami hanya menerima identitas akun dan alamat email untuk mengenali kamu saat masuk; nama dan foto Google tidak dipakai di game. Yang disimpan di server:

  • Nama tampilan (dibuat otomatis, boleh kamu ganti) dan avatar.
  • Statistik, pencapaian, skin terpilih, dan karakter yang sudah terbuka.

Nama tampilan, jumlah pertandingan, dan jumlah kemenangan dapat dilihat pemain lain yang sudah masuk. Email dan data progres lengkapmu hanya bisa dibaca olehmu. Saat pertama masuk, progres di perangkat ini digabung ke akunmu (tidak menimpa data akun yang sudah ada). Keluar akun tidak menghapus data lokal. Untuk menghapus akunmu beserta datanya, hubungi pemilik game; data dihapus permanen.

Yang disimpan di perangkatmu

Disimpan di penyimpanan browser (localStorage), hanya di perangkat ini, dan tidak dikirim ke mana pun:

  • Pilihan alat kontrol dan pengaturan (volume, getaran, grafis).
  • Statistik permainan, pencapaian, dan karakter yang sudah terbuka.
  • Salinan file game, supaya bisa dibuka tanpa internet.

Semua itu hilang kalau kamu menghapus data situs ini dari browser.

Yang melibatkan pihak lain

  • Hosting. Situs ini dilayani oleh Vercel. Seperti server web pada umumnya, Vercel dapat mencatat alamat IP dan jenis browser saat halaman dimuat.
  • Huruf. Huruf tampilan dimuat dari Google Fonts, sehingga browser-mu menghubungi server Google saat halaman dibuka.
  • Mabar online. Hanya kalau kamu membuat atau bergabung ke room. Server PeerJS publik dipakai untuk mempertemukan perangkat lewat kode room. Setelah tersambung, data permainan mengalir langsung antar-perangkat, sehingga alamat IP-mu terlihat oleh perangkat pemain lain di room yang sama (dan oleh server perantara bila sambungan langsung tidak memungkinkan). Isi yang dikirim hanya tombol yang ditekan dan keadaan permainan.

Anak-anak

Game ini tidak mengumpulkan data pribadi dari siapa pun, termasuk anak-anak.

Perubahan

Kalau cara kerja game berubah (misalnya nanti ada papan peringkat), halaman ini diperbarui lebih dulu.
